# Hotel-Reservation-System
A system that allows hotel staff to book rooms with time slots for guests.

## Features
Create Guest Accounts
Search for Specific Guests
Different Types of Hotel Rooms
View Rooms Currently Available
Create Reservations for Guests
Prevent Double Booking
Calculate Costs for Booking

## Planned

Error Handling with Invalid Inputs
Writing a File for Newly Created Reservations
